# qa_python
В файле tests.py мной были реализованы следующие тесты:
    1. У новой добавленной книги отсутствует жанр
    2. Не добавляется книга с именем более 40 символов
    3. Не добавляется книга с тем же именем
    4. У книги устанавливается жанр, если жанр есть в списке доступных
    5. Можно получить книгу с нужным жанром из списка
    6. Получение книг с жанром, подходящим детям
    7. Неподходящие жанры не попадают в список книг для детей
    8. Книга из списка добавляется в избранное
    9.Книга удаляется из избранного

Тестовое покрытие составляет 97%.

Использована параметризация для нескольких тестов.
